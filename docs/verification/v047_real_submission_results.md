# v0.4.7 実Kaggle提出結果 — ローカル検証と実リーダーボードの相関、機序込みで解明

**提出日:** 2026-08-31。両競技合計10件(各5件)を実際にKaggleへ提出
(`kaggle competitions submit`)。ユーザーの明示的な許可(「提出してください」)を
得てから実行した。全10件`SubmissionStatus.COMPLETE`、public/privateスコアとも
即時判明(両コンペとも終了済みのため)。

**選定方法:** [c_lite_v047_policy.md](../c_lite_v047_policy.md)§2.3〜2.4で確定した
機械的基準(ローカルsealed transfer AUC上位4体+全個体のrank-averageブレンド、
盲検インシデントでタイントと判定された個体は除外)——約選定プロセスの詳細な経緯
(却下した5つの代替案を含む)は同文書§2.3を参照。

## 1. 最重要結果:ローカルAUC順位と実リーダーボード順位の相関は、コンペによって
**正反対**だった——分布シフトの有無で完全に説明できる

| コンペ | ローカルAUC vs 実public score の順位相関(Spearman ρ、n=4) |
| --- | ---: |
| IEEE-CIS | **-1.000**(完全に逆転) |
| Santander | **+1.000**(完全に一致) |

**IEEE-CIS:** ローカルで最良だった`agent-02-r2`(sealed transfer AUC 0.8784)は、
実public scoreでは4体中**最下位**(0.8727)。逆にローカル4位だった`agent-04-r2`
(0.8730)が実public scoreでは**最上位**(0.8827)。

**Santander:** 完全に一致——`agent-05-r1`がローカルでも実スコアでも最良、
`agent-04-r1`がローカルでも実スコアでも最下位。

**これは偶然ではない。** [v0.4.7世代1結果](v047_generation1_results.md)で独立検証した
通り、**IEEE-CISには実際のtrain/test間に本物の分布シフトが存在する**(Controller自身が
生データから再現したadversarial validation AUC 0.622、chance=0.5を明確に超える)。
一方**Santanderには分布シフトがない**(複数のエージェント報告・Controller検証とも、
research/confirmation/transfer/real_testが同一分布であることを確認済み)。

**機序の説明:** train.csvの一部を封印して作る「sealed transfer」は、定義上
train.csvの分布からしか抽出できない。**分布シフトが存在するコンペでは、
sealed transferでの高スコアは「訓練分布に過適合している」ことの裏返しであり、
実際にシフトした本番データではその過適合が仇になる**——ローカルスコアが高いほど
実スコアが低くなるという、単なる「無相関」を超えた**負の相関**が生じうる。
逆に分布シフトが存在しないコンペでは、sealed transferは本番データの忠実な
代理であり続け、ローカル順位がそのまま実順位になる。

**これは、本プロジェクトが`docs/progress.md`(ERL v0.3.x時代)以来問い続けてきた
「ローカル検証はリーダーボードを予測できるか」という問いに、単なる相関の強弱では
なく、\*\*「分布シフトの有無」という具体的で検証可能な機序込みで\*\*答えを与える結果である。**
n=4/コンペと小さく統計的検定力は低いが、パターンの明確さ(±1.000という完全な
一致・逆転)と、独立に確認済みの機序(シフトの有無)が組み合わさっているため、
偶然の産物とは考えにくい。

## 2. アンサンブル(ブレンド)の効果もコンペ依存だった

| コンペ | ブレンドのpublic | 個体最良のpublic | ブレンドは個体最良を超えたか |
| --- | ---: | ---: | :---: |
| IEEE-CIS | 0.8818 | 0.8827(agent-04-r2) | わずかに届かず、ただしprivateでは0.8618で4体中最良 |
| Santander | 0.8710 | 0.8890(agent-05-r1) | 大きく下回る |

**IEEE-CIS(分布シフトあり)ではブレンドが健闘し(private scoreでは個体最良を上回った)、
Santander(シフトなし)ではブレンドが単体最良に明確に劣った。** これも上記の機序と
整合する——分布シフトがある状況では、どの個体が「本当に良い」かをローカルだけで
見極めにくいため、複数の異なる個体を平均することがヘッジとして機能する。シフトが
ない状況では、最良個体を薄めるだけで損になる。

## 4. Santanderのreal/synthetic発見は、実スコアにどう反映されたか

[世代1結果](v047_generation1_results.md)で本プロジェクト初到達と報告した、real/synthetic
行判定を発見した2体(`agent-05-r2`・`agent-06-r1`)のうち、`agent-06-r1`は実際に
高い実スコア(public 0.8857、4体中2位)を達成した。ただし発見そのもの
(頻度エンコーディングは+0.001程度)は最終モデルにほぼ寄与しておらず、高スコアの
主因は別の手法(isotropic quadratic/dispersion成分の活用)だった——[世代1結果](v047_generation1_results.md#1-最重要発見santanderの核心技術1-realsynthetic行判定に本プロジェクト初到達)
で既に指摘した「発見」と「活用」の分離が、実スコアでも裏付けられた形になる。

## 5. 限界

- n=4/コンペの単一ラウンド。相関係数の完全な±1.000は、サンプルサイズの小ささ
  ゆえに偶然でも起こりうる値であり、統計的に確定した結論ではない——ただし機序
  (分布シフトの有無)が独立に確認されていることが、単なる偶然の相関以上の
  説得力を与えている。
- 今回は2競技・1ラウンドのみ。今後さらに競技・ラウンドを重ねれば、この
  「シフトの有無が局所-実相関を決める」という仮説の頑健性を検証できる。
- Private scoreは両コンペとも終了済みのため即時判明したが、実際の進行中コンペでは
  この比較(public即時・private終了後)は成立しない——この検証環境固有の利点である
  ことに留意。
