## 0. なぜ追補が要るか

一次版は事前登録した基準を満たした(context 条件付け 0.8745 対 チェックリスト 0.8462、
95% 区間 [+0.0121, +0.0466])。**しかし反例を 1 件も再現しない。**
真に `−1` の 6 セルに対し、両予測子とも `−1` を出さない([results.md](results.md) §2.3)。

`−1` は**チェックリスト化を防ぐために置いた唯一の仕掛け**である
(`research_models.md` §341)。当てはめた世界モデルがそれを出力できないなら、
出力を使う側から見た世界モデルは**チェックリストと区別できない。**

原因は形にある。3 値上の分布を作って `argmax` を取ると、6/494 = 1.2% の水準の値は
**縮約後の分布で最大になりようがない。**値を 3 値の点予測として持つ限り、
corpus をどれだけ広げても `−1` は出ない。

## 1. 何を変えるか(モデルの形)

**決定性と必要性を分けて持つ。**状態 `s`、context セル `c` について 2 つの量を当てはめる。

| 量 | 定義 |
| --- | --- |
| `p_mentioned(s, c)` | **決定性** — その状態が勝敗に関わったか。`P(label ≠ 0)` |
| `p_minus(s, c)` | **必要性の向き** — 関わったとして、それは「高くなければ勝てない」か、その**反証**か。`P(label = −1 \| label ≠ 0)` |

同時分布は `P(+1) = p_mentioned · (1 − p_minus)` / `P(−1) = p_mentioned · p_minus` /
`P(0) = 1 − p_mentioned`。

縮約は一次版と同じ **`k0 = 5`**(prior strength は low に固定、§18)。
`p_mentioned` はセル頻度を状態ごとの全体頻度へ、`p_minus` は**言及されたセルのみ**を
分母として状態ごとの全体の向きへ縮約する。全体側の事前は Laplace 加算 1(2 クラス)。

**これは corpus の再符号化ではない。**同じ `corpus_coding.json` の同じラベルを、
1 つの 3 値分布ではなく 2 つの二値量として当てはめ直すだけである。

## 2. 何を変えるか(決定規則)

    1. P(−1) >= τ            -> −1
    2. さもなくば P(+1) >= 0.5 -> +1
    3. さもなくば              -> 0

**`τ` は保留 domain を一切見ずに、学習側の fold だけで決める。**
規則は「**学習側で `−1` と予測されるセル数が、学習側の真の `−1` セル数の 2 倍を
超えない最小の `τ`**」。真の出現率に対して警報を 2 倍まで許し、それ以上は許さない。
学習側に真の `−1` が 1 件も無い fold では `τ = ∞` とする(`−1` を出さない)。

**`τ` を保留側の結果で選び直さない。**選び直したらそれは検定ではない。

## 3. 評価(事前登録)

一次版と**同じ leave-one-domain-out、同じ 38 コンペ、同じ対応ありブートストラップ
10,000 回・seed 20260906** を使う。比較対象は 3 つ。

| 予測子 | 分布 |
| --- | --- |
| **チェックリスト** | 状態ごとの全体分布(context を無視) |
| **context 条件付け(一次版)** | `coding_rules.md` §5 の 3 値条件付き分布 |
| **2 部モデル(本追補)** | §1 の `p_mentioned × p_minus` |

報告する量:

1. **3 値 Hamming 一致率**(一次版と直接比較できる形)
2. **`−1` の再現数と精度** — 真に `−1` の 6 セルのうち何件を `−1` と予測したか、
   および `−1` と予測したセルのうち何件が真だったか
3. **`+1` の再現数**(真に `+1` の 78 セル。一次版は 31/78、チェックリストは 22/78)
4. **平均対数損失** — 3 値分布をそのまま採点する。点予測の一致率と違い、
   **`−1` に置いた確率質量が評価に入る**
5. 1 と 4 について、**2 部モデル − 一次版**の差の 95% 区間(対応ありブートストラップ)

## 4. 判定基準(事前登録)

**2 部モデルを世界モデルの報告形式として採用するのは、次の両方を満たすときに限る。**

- **(a) 反例を 1 件以上再現する**(leave-one-domain-out で `−1` の予測が 1 件以上当たる)
- **(b) 一致率の劣化が許容内** — 差 `(2 部モデル − 一次版)` の 95% 区間の**下限が −0.01 以上**。
  一次版が積み上げた利得は +0.0283 であり、**その半分以上を反例の再現と引き換えにしない**

**どちらかを満たさない場合:**「点予測として `−1` を再現する形は、この corpus では
費用に見合わなかった」と記録する。**これは失敗ではなく結果である。**その場合でも
`world_model.json` は **`P(−1)` を明示的に持つ分布として出力する** —— 点予測が `−1` を
出せなくても、**出力を読む側には「この状態は 8% の確率で逆に働く」が見える。**
チェックリスト化を防ぐ仕掛けは、点予測ではなく**分布の側**で保つ。
