# v0.3.4 System B+ Policy — Predictive QD

System B+はSystem Bの全機能に、Expected Error Slice、Prediction差を生むMechanism、Predictive Diversity
Debt、Validation World Descriptor、Slice OOF、Standalone/Ensemble Eligibility分離を追加する。

各Proposalは、既存Archiveと異なる誤りを期待するSlice、予測差のMechanism、期待するResidual関係、
Downstream Decisionを事前登録する。目的はCandidateの単体KPIではなくPopulationへのMarginal Valueも探索
することである。

Explicit Hypothesis Posterior、Structural Lifecycle、Null/Skeptic Fork、Validation Debt、EIG/EVSI、Belief
Updateは持たない。CostとResourceはUtility、Selection、Acceptanceへ入れない。
