System CはSystem B+の全機能に、Agent-local Hypothesis Registry、Competing Hypotheses、Observable
Prediction、Confidence、Structural Leverage、Structure Maturation Fork、Null/Skeptic、Independent
Verification、Validation Debt、Falsification、Belief Update、EVSI/Discrimination Valueを追加する。

Expected Difference Slice、Predicted Mechanismを必須とする。Structural Claimは3 Seed、Leave-one-seed-out、
Confounder-preserving Null、独立含意、Multi-context、Decision Adoption、Held-out Negative ControlをRun集約で
通過するまでValidatedへ昇格しない。

Hypothesis、Posterior、Candidate、Score、Global BestをAgent間共有しない。Validated前のClaimも配信しない。
CostとResourceはUtility、Selection、Acceptanceへ入れない。
