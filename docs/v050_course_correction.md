# v0.5.0 方針転換 引き継ぎ書 — 何を間違えていたか、ここからどうするか

**作成:** 2026-09-06
**決定:** **ラウンド5(10 体)を停止した。**NEDO の population 増設は当面行わない
**関連:** [世界モデル構築](world_model_handover.md) / [v0.5.0 の教訓](v050_lessons.md) / [引き継ぎ書](handover.md)

## 要旨

**NEDO で 4 ラウンド・51 体を回したが、それは System C-lite の実行ではなかった。**
population を持った System A である。したがって**この campaign は C-lite の価値について
何も言っていない。**同時に、C-lite の中核入力である**世界モデルは一度も作られておらず、
その素材は最初から repo にあった。**

**順序を間違えていた。**世界モデル無しの C は C ではなく、弱い B との比較は
仕様(`research_basis_and_design_rationale.md` §1917)が禁じている。
**個体を足す作業を止め、順序を戻す。**

## 1. 何を間違えていたか

### 1.1 蓄積を使わず、作り直した

| | 仕様 | 実際 |
| --- | --- | --- |
| **世界モデル** | 38 コンペ corpus から context 条件付き分布(§245) | **`DEFAULT_PREFERRED_TARGETS` に手書き定数 7 個。13 状態のうち 6 が定数、7 が欠落** |
| **層2 taxonomy** | データ形式非依存のメタ技術クラス | **2 コンペ・1 ドメイン(表形式)。看板が実体と合っていない** |
| **NEDO の taxonomy** | preregister 時点で層1 と層2 の両方を作る(層2文書の明文の手順) | **層1 すら存在しない** |

引き継ぎ書に自分でこう書いていた —「**継承したのは population × 設計軸 → 機械的選定 →
実スコアで親選定というループ構造だけ**」。**ループを継承して蓄積を捨てた。**
ループは作り直しがいちばん安い部分である。

そして捨て方が広すぎた証拠が出ている。**13 状態のうち 4 つを、仕様にあると知らないまま
別名で再発明していた** — 較正(Validation Fidelity)、分解能 32/√n(Robustness)、
課題ごとスコア相関 0.368(Error Diversity)、解法族の調査(Representation Coverage)。
**予測問題ですらない出題で 4 つが再現した。**

### 1.2 回している系を取り違えていた

| | 手段 | 世界モデル | 選択 |
| --- | --- | --- | --- |
| System B | 固定 | — | 効用に novelty / QDContribution |
| System C-lite | 自由 | **共有し更新する** | EIG / EVSI |
| **実際に回したもの** | 自由 | **固定・無更新** | **スコアの argmax** |

**B ですらない。**novelty 項が効用に無いので、**51 体が同じ事前分布から自由に選べば
最頻解に着地する。**「70 体回しても解法族が割れない」を campaign 最大の発見として
書いたが、**これは設計から演繹できる挙動であって発見ではない。**

### 1.3 広い事前分布を、狭い自分の主張で上書きした

エージェントは LLM であり、**事前学習によって多数のコンペの上位解法の像を既に持っている。**
仕様が「LLM contamination」として失敗要因に挙げているものが、実は**唯一存在する
広域の世界モデル**だった。

そこへプロンプトの**「分かっている事実(ラウンド0の実測)」**として、

> **ボトルネックは詰め方ではなく到達可能性。**

を置いた。根拠は **128 問すべてでゲートに落ちる 2 つのベースラインだけ**で、
**以後一度も検定していない。**強度の表示も反証条件も無い断定として、**51 体全部に配った。**
prior strength を low に固定せよという規則の正反対である。

### 1.4 一度の反証から、探索の枠組みごと畳んだ

ラウンド2 で探索アーム(知見を文章だけで渡す)が親比 **−7.52**。
「**文章では伝わらない**」と結論し、**仮説水準の作業ごと終了した。**
正しい結論は「**その表現形式では伝わらない**」である。
**C-lite が campaign から消えたのはこの 1 回の判断である。**

### 1.5 測定の規律を、自分で作った規則の側で破った

- 分解能 32/√n を測る前に、σ 2.58 の 12 問で 2〜3 点差に順位を付けていた。
  128 問で測り直して**4 件の結論が反転**
- そのうえで、**分解能を戒める文書の中で同じ誤りを繰り返した。**
  「順位 10 位の r3-03 が最良の交配相手」の根拠は、**4 セル中で平均が最下位(53.87)の
  セルの最大値**を拾ったもの。差 0.51 は分解能 ±2.8 の内側 → **撤回する**
- 盲検を意図的に廃止し、**falsifier の独立性を失った**

### 1.6 目的の置き換えを明示しなかった

締切 2026-10-19、賞金 1500 万円。**リーダーボードを最適化し、ERL を手段として使った。**
勝つためには貪欲系が正しく、学ぶためには誤っている。**このトレードオフを一度も
書き出さず、ユーザに確認もしなかった。**

### 1.7 装置の運用

API 断で計画を焼き切る事故 2 回(21 体 → 対策後 6 体)、監督の同期ブロック、
`pgrep -f` の自己マッチ**3 回目**、残骸で並列度が 1/6、遊休機 8 時間。
詳細は [v0.5.0 の教訓](v050_lessons.md) §3。**すべて「監督が現実ではなく自分の帳簿を
見ていた」型である。**

## 2. 間違えていなかったこと

公平のために残す。**これらは C-lite 的な作業の産物である。**

- **採点系の同定** — ゲート閾値 0.48、較正 傾き 0.589、dev−sealed +1.71
- **厳格マージン仮説の棄却** — 在圏 RMSE 1.33、圏外 14.42 で棄却。
  **事前登録と圏外検証がなければ採用していた**
- **分解能の法則 32/√n** — n=8〜128 で乖離 0.23 点以内
- **進化 +3.00 対 探索 −7.52** — 唯一、分解能を超えた軸
- **実 public 63.797**(r3-13)

**事前に書けなかったのは、すべて仮説・事前登録・反証・較正を伴う部分の産物である。**
population を回した部分が返したのは、ほぼ null と装置の穴だった。

## 3. ここからの方針

### 3.1 順序を戻す

仕様 §1917:「**System B が弱い状態で System C を比較してはならない**」。
世界モデルは C の入力であって B の構成要素ではない。したがって:

| 順 | やること | 状態 |
| ---: | --- | --- |
| 0 | **NEDO の population 増設を止める** | **実施済み(r5 停止)** |
| 1 | **記録の訂正** | 未 |
| 2 | **強い B を作る** — 効用に novelty / QDContribution を入れる | 未 |
| 3 | **世界モデルを作る** — [手順書](world_model_handover.md) | 未 |
| 4 | **C と B を比較する** — 検出力を先に設計する | 未 |

**3 を 4 の前に置くこと。世界モデル無しの C は C ではない。**

### 3.2 目的を 2 つに分離し、混ぜない

| | 目的 | 判定 | 系 |
| --- | --- | --- | --- |
| **競技** | NEDO で順位を取る(締切 10-19) | 実 public | **貪欲でよい。それが正しい** |
| **研究** | C-lite に価値があるか | 事前登録した比較 | **強い B との対照が要る** |

**競技の結果を研究の証拠として提示しない。**この 2 つを混ぜたことが 1.6 の中身である。
NEDO はこれ以降**競技として**継続し、**C-lite の証拠としては引用しない。**

### 3.3 記録の訂正(1 の帰結、今日できる)

1. **[v0.5.0 の教訓](v050_lessons.md) §2.2 を撤回する** — 「順位と交配相手としての
   価値は別」の根拠は分解能内。§4 の 10 機構に「**実行前から可能だったか**」列を足し、
   **harvest ではなく負債の返済である**と明記する
2. **層2 taxonomy を改名する** — 「データ形式非依存」を外し、
   **表形式 2 コンペ由来**であることと、昇格条件が緩すぎた(2 コンペで昇格)ことを記す
3. **装置クラスの層2 を新設する** — 2 問題クラスで独立観測済みで昇格条件を満たす:
   「ローカル指標が実は別の量を測っている」「ローカルは差を誇張する(傾き<1)」
   「課題セットが張っていない軸は装置の盲点になる」
4. **NEDO プロンプトの「分かっている事実」を解体する** — 「ボトルネックは到達可能性」を
   **事実の節から外し、強度と反証条件を付けた仮説として置き直す。**
   あわせて手元の 128 × 51 で検定する(追加の計算資源は不要)

### 3.4 やらないこと

- **リーダーボードを追って個体を足しながら、それを研究の進捗として報告すること**
- **世界モデル無しで「C-lite を回した」と称すること**
- **分解能を測らずに軸の効果を語ること**

## 5. NEDO の扱い

**競技としては継続する**(締切 10-19、提出枠 5/日)。既存 51 体から選んで提出する
作業は研究とは独立に進めてよい。**提出前に無負荷での実行時間測定が必須** ——
上位に `policy` 7.45〜8.12s の個体があり、負荷下の計測は水増しされる。

**研究上の役割は変わる。**NEDO は今後、

1. **世界モデルの最初の問題クラス外テストケース**(提出物が予測値ではなくアルゴリズム)
2. **装置クラスの層2 を裏づける 2 つ目の問題クラス**

として使う。**population を回して C-lite の証拠を作る場としては使わない。**

## 6. 判定の条件(先に書いておく)

- **世界モデル:** leave-one-domain-out で「どの状態が決定的か」の予測が、事前登録した
  base rate を上回るか。**上回らなければ「転移しない」と記録する。それは結果であって失敗ではない**
- **強い B:** novelty 項を入れた B が、入れない現行より**族の多様性**を上げるか
  (分解能を先に設計すること)
- **C 対 B:** 両腕に同じ世界モデルを渡し、差は**手段を割り当てるか自分で選ばせるか**のみ。
  **各腕 5 体では検出力が足りない**(腕平均の差は 6 点必要)。体数を先に決めること
