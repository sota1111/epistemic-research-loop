## 0. この文書は何か

ERL は「KPI を改善する AI」ではなく「**未知の勝ち筋を発見する AI**」に価値があるかを
検証するための装置である([research_models.md](research_models.md))。
その検証は**まだ一度も成立していない。**

この文書は、**何が足りないか**と**どの順で埋めるか**を、
2026-09-06 のセッションで確定した事実に基づいて書く。

## 1. 最初に直面すべき事実

### 1.1 唯一の実運用は、エンジンを一度も使っていない

`erl-nedo-baggage-loading` に `epistemic_loop` / `erlctl` の参照は **0 件**である。
70 体・4 ラウンドを回した唯一の campaign は、**エンジンを迂回して別の道具一式を
その場で作り直した。**しかもそこで作り直したもの(population、進化、交配、選定)は
**エンジンが既に持っている**。

capability matrix には **61 件の enforced** が並んでいる。**そのどれも、実運用で
使われた実績がない。**「機能が足りない」のか「使われなかっただけ」なのかは
**まだ判定できていない。完成の第一条件はここである。**

### 1.2 世界モデルは作られていなかった。一次版を作った

`DEFAULT_PREFERRED_TARGETS` は corpus 由来ではなく**手書きの定数 7 個**で、
仕様(§245)の 13 状態のうち **6 が定数・7 が欠落**、しかも §247 が
「最も危険」と名指しした**固定ベクトル + 数値チェックリスト**の形だった。

2026-09-06 に一次版を作った([結果](world_model/results.md))。

| | |
| --- | --- |
| 素材 | `research_models.md` §44 の 38 コンペ(tabular / forecasting / cv / nlp / recsys / other) |
| 符号化 | 状態の**値**ではなく**決定性** `+1 / 0 / −1`。反例 `−1` を明示的に持つ |
| 条件付け | domain ではなく**構造属性 3 つ**(temporal / entity / decomposable) |
| 検証 | leave-one-domain-out、対応ありブートストラップ |

**結果:** context 条件付け 0.8745 対 チェックリスト 0.8462、差 **+0.0283**、
95% 区間 **[+0.0121, +0.0466]**。**区間が 0 をまたがない。**
§247 の「固定ベクトルではなく context 条件付き分布」は**保留 domain で成立した。**

### 1.3 ただし、その一次版には 3 つの穴がある

1. **利得は時間構造を持つ domain からしか出ない。**cv / nlp / other では
   context モデルの予測がチェックリストと**完全一致**した。3 特徴のうち 2 つが
   これらの domain でほぼ定数になるため
2. **一致率は多数派に支配されている。**494 セル中 410 件(83%)が `0`。
   真に決定的な 78 セルの再現は **31/78**(チェックリストは 22/78)
3. **反例を 1 件も再現できない。**真に `−1` の 6 セルに対し、両予測子とも
   `−1` を出さない。**チェックリスト化を防ぐ唯一の仕掛けが、当てはめで消える**

### 1.4 **winner corpus は、C-lite の当の部分に事前分布を供給できない**

38 コンペ全部で観測ゼロの状態が 2 つある。

| 状態 | 観測 |
| --- | ---: |
| **Hypothesis Calibration** | **0** |
| **Falsification Coverage** | **0** |

write-up は成功後に書かれ、**失敗した仮説と確信度の履歴は残らない**(§101 の
survivorship / hindsight bias)。**そしてこの 2 つこそ C-lite を B から区別する構成要素である。**

> **corpus をどれだけ広げても、C-lite の価値は決まらない。実験でしか決まらない。**

これは `research_models.md` §101 が「Epistemic Value を目的へ入れると Private LB が
上がるという証拠はまだない。実験で検証すべき未確立仮説である」と書いていたことの、
**corpus 側からの独立確認**である。**ERL の存在理由は、この 1 つの実験に懸かっている。**

## 2. プログラム水準で間違えていたこと

### 2.1 蓄積を使わず、その場で作り直した

世界モデル(§1.2)、層2 taxonomy(「データ形式非依存」を名乗って実体は**表形式 2 コンペ**)、
コンペ別 taxonomy(**層1 すら未作成**)。**エンジンも同様に迂回された(§1.1)。**

引き継ぎ書に自分で書いていた —「継承したのはループ構造だけ」。
**ループを継承して蓄積を捨てた。ループは作り直しがいちばん安い部分である。**

### 2.2 回している系を取り違えた

| | 手段 | 世界モデル | 選択 |
| --- | --- | --- | --- |
| System B | **固定** | — | 効用に novelty / QDContribution |
| System C-lite | 自由 | **共有し更新する** | EIG / EVSI |
| 実際に回したもの | **自由** | **固定・無更新** | **スコアの argmax** |

**B ですらない。**そして「70 体回しても解法族が割れない」を最大の発見として書いたが、
**novelty 項の無い設計から演繹できる挙動であって、発見ではない。**

### 2.3 広い事前分布を、狭い自分の主張で潰した

エージェントは LLM であり、**事前学習によって多数のコンペの像を既に持っている。**
仕様が「LLM contamination」として失敗要因に挙げるものが、**実は唯一存在する
広域の世界モデル**だった。

そこへプロンプトの「**分かっている事実**」として、根拠が**全問ゲート落ちの
ベースライン 2 本だけ**の主張を、**強度も反証条件も付けずに全個体へ配った。**
`prior strength を low に固定せよ`(§18)の正反対である。

### 2.4 一度の反証から、枠組みごと畳んだ

探索アーム(知見を文章だけで渡す)が親比 **−7.52** →「文章では伝わらない」と結論し、
**仮説水準の作業ごと終了した。**正しい結論は「**その表現形式では**伝わらない」。
**C-lite が campaign から消えたのはこの 1 回の判断である。**

### 2.5 測定の規律を、自分で作った規則の側で破った

分解能(半幅 = 32/√問数)を測る前に σ 2.58 の 12 問で順位を付け、**4 件の結論が反転**した。
そのうえで、**分解能を戒める文書の中で同じ誤りを繰り返した**(「順位 10 位の個体が
最良の交配相手」の根拠は、4 セル中**平均最下位のセルの最大値**。差 0.51 は ±2.8 の内側)。
**撤回する。**

### 2.6 目的の置き換えを明示しなかった

締切と賞金のある競技を回し、**リーダーボードを最適化して ERL を手段として使った。**
勝つためには貪欲系が正しく、学ぶためには誤っている。
**このトレードオフを一度も書き出さず、確認もしなかった。**

### 2.7 **計画を書いて、実物を作らなかった**

このセッションで引き継ぎ書を 3 通書いた。**世界モデルの実物は、
「作成しないのですか」と指摘されるまで作らなかった。**手順書は成果物ではない。

**対策:** 以後、**完成条件を「文書がある」ではなく「成果物と検証結果がある」で書く**
(§5)。文書だけの節を作らない。

## 4. 順序

    1 エンジンを通す  ->  2-4 測定の規律  ->  5-8 世界モデルを使える形に
                                          ->  9-10 taxonomy の是正
                                          ->  11 強い B  ->  12 C 対 B

**11 を 12 の前に**(§1917)。**5〜8 を 12 の前に**(世界モデル無しの C は C ではない)。
**2 を全部の前に**(分解能が無ければ 11 も 12 も判定できない)。

### 12 の設計(先に書いておく)

両腕に**同じ世界モデル**を渡す。渡さないと「情報量が多かっただけ」と交絡する。

| | B 腕 | C-lite 腕 |
| --- | --- | --- |
| 世界モデル | 渡す | 渡す(同一文面) |
| 手段 | **割り当てる** | **本人が選ぶ** |
| 仮説 | 不要 | **着手前に登録**(何に賭けるか / 反証条件) |
| 反証 | なし | **自分で検定を設計し、失敗も報告する** |

**検出力:** 個体単位の分解能 ±2.8、個体間の広がり 4〜5 点。
**各腕 5 体では腕平均の差が 6 点ないと分離できない。**
進化 対 探索(10.5 点)は分離できたが、**C 対 B がそこまで開くとは考えにくい。
体数を先に決めること。**

## 5. 完成の判定条件

**すべて「文書がある」ではなく「成果物と検証結果がある」で書く**(§2.7)。

1. **エンジン:** `erlctl` で 1 コンペを最後まで回した run が 1 本あり、その event log から
   `erlctl report run` が出ている
2. **分解能ゲート:** 区間が 0 をまたぐ比較で順位が返らないことを示すテストがある
3. **世界モデル:** 独立符号化の一致率が報告され、leave-one-domain-out の結果が
   事前登録した base rate と比較して報告されている。**上回らなくても、報告されていれば条件を満たす**
4. **強い B:** novelty 項を入れた B が、入れない構成より族の多様性を上げるかが
   **分解能を設計したうえで**測られている
5. **C 対 B:** 事前登録した体数・指標で実施され、**差が無いという結果でも公表されている**

**5 で「差が無い」が出たら、Epistemic Layer を追加する価値は確認できなかったと結論する。**
それが `research_models.md` が設計した反証可能性であり、**その結論を出せることが完成である。**

## 7. 個別コンペの扱い(参考)

NEDO は**競技として**継続する(締切 2026-10-19)。**研究の証拠としては引用しない。**
population の増設は 2026-09-06 に停止した。

研究上の役割は 2 つに限る。

1. **世界モデルの最初の問題クラス外テストケース** — 提出物が予測値ではなく
   アルゴリズムで、`temporal=0 / entity=1 / decomposable=1`
2. **装置クラス層2(§3 の 10)を裏づける 2 つ目の問題クラス**

なお NEDO は、**13 状態のうち 4 つが問題クラスを越えて再現する**証拠も出している —
較正(Validation Fidelity)、32/√n(Robustness)、課題ごと相関 0.368(Error Diversity)、
族の調査(Representation Coverage)。**仕様にあると知らないまま別名で作り直した。**
